## 🚀 Featured Projects

### 💼 [Job Portal: Full Stack Backend Application](https://github.com/abhaykumar432/REPLACE-WITH-JOB-PORTAL-REPO)
Backend for a job portal with REST APIs for job listings, applications and bookmarking, built with a layered architecture.
- JWT auth (access + refresh tokens) with a custom `AuthenticationProvider` and role-based access for candidates, employers and admins
- Query optimization with JPQL and batch fetching; **Redis caching improved response times by 30–40%**
- Containerized with Docker Compose; uses Kafka, AWS S3 and MongoDB

`Java` `Spring Boot` `Spring Security` `Hibernate/JPA` `MySQL` `Redis` `Kafka` `Docker` `AWS S3`

### 🧠 [C.O.S.M.O.S.: Real-Time EEG-Based Stroke & Cognitive Stress Assessment](https://github.com/abhaykumar432/REPLACE-WITH-COSMOS-REPO)
Wearable dual-channel frontal EEG (F3/F4) system for rapid stroke and cognitive-stress screening, aimed at reducing diagnostic delay in the critical "Golden Hour".
- Edge-processing layer with artifact cleaning and FFT to isolate Alpha/Delta bands
- Computes **Brain Symmetry Index (BSI)** and **Alpha-to-Delta Ratio (ADR)** as real-time markers
- High-concurrency Spring Boot backend with REST/WebSockets and a clinical dashboard for triage alerts

`Java` `Spring Boot` `FFT` `WebSockets` `Cloud-Edge Architecture`

### 🤖 [AI-Powered API Test Automation Framework](https://github.com/abhaykumar432/REPLACE-WITH-TEST-FRAMEWORK-REPO) *(in progress)*
