### 💼 Job Portal — Full Stack Backend Application

![Java](https://img.shields.io/badge/Java-F59E0B?style=flat-square&logo=openjdk&logoColor=0F172A) ![Spring Boot](https://img.shields.io/badge/Spring_Boot-10B981?style=flat-square&logo=springboot&logoColor=white) ![Spring Security](https://img.shields.io/badge/Spring_Security-10B981?style=flat-square&logo=springsecurity&logoColor=white) ![Redis](https://img.shields.io/badge/Redis-DC382D?style=flat-square&logo=redis&logoColor=white) ![Kafka](https://img.shields.io/badge/Kafka-231F20?style=flat-square&logo=apachekafka&logoColor=white) ![Docker](https://img.shields.io/badge/Docker-0EA5E9?style=flat-square&logo=docker&logoColor=white)

- **Layered REST backend:** Spring Boot + Spring Data JPA with APIs for job listings, applications and bookmarking.
- **Auth & RBAC:** JWT (access/refresh tokens) with a custom `AuthenticationProvider` and role-based access for candidates, employers and admins.
- **Performance:** JPQL + batch fetching, and Redis caching that cut response times by **30–40%**.
- **Infra:** Docker Compose, Kafka messaging, AWS S3 storage and MongoDB.

### 🧠 C.O.S.M.O.S. — Real-Time EEG-Based Stroke & Cognitive Stress Assessment

![Java](https://img.shields.io/badge/Java-F59E0B?style=flat-square&logo=openjdk&logoColor=0F172A) ![Spring Boot](https://img.shields.io/badge/Spring_Boot-10B981?style=flat-square&logo=springboot&logoColor=white) ![FFT](https://img.shields.io/badge/FFT-6366F1?style=flat-square) ![WebSockets](https://img.shields.io/badge/WebSockets-0EA5E9?style=flat-square)

- **Problem:** rapid stroke and cognitive-stress screening to reduce diagnostic delay in the critical "Golden Hour".
- **Edge layer:** artifact cleaning + FFT to isolate Alpha/Delta bands from dual-channel frontal EEG (F3/F4).
- **Markers:** real-time **Brain Symmetry Index (BSI)** and **Alpha-to-Delta Ratio (ADR)**.
- **Backend:** high-concurrency Spring Boot with REST/WebSockets and a clinical dashboard for triage alerts and stress trends.
